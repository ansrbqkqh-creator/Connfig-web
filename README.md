# connfig — 사이트 v1

> **성과를 내는 편안함 (Comfort that performs)**
> 편안함을 *성과로* 설계하는 상업·오피스 인테리어 스튜디오.

순수 정적 사이트(HTML/CSS/JS)로 만든 v1입니다. 빌드 도구·의존성 없이 `index.html`만 열면 바로 동작합니다.

## 구성

| 파일 | 역할 |
|------|------|
| `index.html` | 전체 페이지 구조 + 카피 |
| `styles.css` | 디자인 — 정밀(config) × 따뜻함(comfy), `nn` 모티프 |
| `script.js` | 모바일 메뉴, 스크롤 등장, 분기→폼 자동 선택, 폼 검증 |

## 섹션

1. **히어로** — “오래 머무는 공간엔 이유가 있습니다.”
2. **방향성** — 편안함은 감성이 아니라 성과 + 세 가지 가치
3. **고객 분기** — 디자인+시공 / 설계만
4. **프로세스** — 듣기 · 구성(config) · 시공 · 머무름
5. **사례** — 니즈 → 해석 → 결과 (예시 3개, 실제 데이터로 교체)
6. **문의** — 공간 유형 · 평수 · 범위 · 한 줄 고민

## 디자인 노트

- **모티프**: `nn`(double-n)을 로고·섹션 번호(`n01…`)·아이콘·사례 썸네일에 반복 노출
- **팔레트**: warm paper(`#F6F2EB`) · 딥 차콜(`#211D18`) · 클레이 액센트(`#B5562F`)
- **타이포**: 본문 Pretendard, 헤드라인·숫자 Fraunces(serif) — 정밀함에 온기 추가
- 한글 가독성을 위해 `word-break: keep-all` 적용, `prefers-reduced-motion` 대응

## 로컬에서 보기

```bash
# 아무 정적 서버나 사용
python3 -m http.server 8000
# → http://localhost:8000
```

또는 `index.html` 파일을 브라우저로 바로 열어도 됩니다.
